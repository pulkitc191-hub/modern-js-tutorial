============================================================
        Memory Management in JavaScript: Stack vs Heap
============================================================

In JavaScript, memory is conceptually divided into two main components: 
the Stack and the Heap. How memory is assigned depends on the data type.

------------------------------------------------------------
1. Stack Memory (Primitive Data Types)
------------------------------------------------------------
- Used for: Primitive Data Types (String, Number, Boolean, Symbol, null, undefined, BigInt).
- How it works: Stack memory stores the actual values of primitives directly. 
- Behavior (Pass by Value): When you assign a primitive variable to another variable, a completely new COPY of that value is created in the stack.

Example Scenario:
If you have variable `A` stored in Stack Memory and assign it to variable `B` (`B = A`), `B` gets a copy of `A`'s value. 
If you later change the value of `B`, `A` remains completely unaffected because `B` was just modifying its own copy.

------------------------------------------------------------
2. Heap Memory (Non-Primitive / Reference Data Types)
------------------------------------------------------------
- Used for: Non-Primitive Data Types (Objects, Arrays, Functions).
- How it works: Heap memory stores the actual data/object. However, the variable itself (stored in the stack) just holds a REFERENCE (a memory address) pointing to that location in the Heap.
- Behavior (Pass by Reference): When you assign an object/array variable to another variable, they both receive the SAME reference pointing to the SAME object in the Heap memory. 

Example Scenario:
If you have an object variable `A` and assign it to variable `B` (`B = A`), both `A` and `B` now point to the exact same location in the Heap. 
If you modify a property inside `B`, those changes WILL reflect in `A` as well, because both variables refer to the identical original value in the Heap memory. 

------------------------------------------------------------
SUMMARY
------------------------------------------------------------
- Stack = Primitives. Gives you a COPY of the value. Changes to the copy do not affect the original.
- Heap = Non-Primitives (References). Gives you a REFERENCE to the value. Changes to the reference DO affect the original.
