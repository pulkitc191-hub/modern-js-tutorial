============================================================
                  JavaScript Variables - Notes
============================================================

WHAT ARE VARIABLES?
-------------------
- Variables are containers used to store different types of data.
- In JS, you declare a variable using: let, const, or var.
- Avoid using var as it is outdated.

------------------------------------------------------------
DECLARATION KEYWORDS
------------------------------------------------------------

  Keyword | Re-assignable | Re-declarable | Use when...
  --------|---------------|---------------|-------------------------
  let     | YES           | NO            | Value will change later
  const   | NO            | NO            | Value stays fixed
  var     | YES           | YES           | Avoid (old style, buggy)


  let studentName = "Pulkit";     // can be changed later
  const studentId  = "210123";    // cannot be changed


------------------------------------------------------------
WHY AVOID var?
------------------------------------------------------------
  - var is function-scoped, not block-scoped.
  - It can be re-declared, which causes hard-to-find bugs.
  - It gets "hoisted" to the top of its scope with value
    undefined, leading to unexpected behaviour.
  - Always prefer let or const in modern JavaScript.


------------------------------------------------------------
NAMING CONVENTIONS
------------------------------------------------------------
  - Use camelCase for variable names  →  studentName, totalMarks
  - Names are case-sensitive          →  name ≠ Name ≠ NAME
  - Cannot start with a number        →  2name ✗
  - Can start with $ or _             →  _temp, $value ✓
  - Avoid reserved keywords           →  let, for, if, etc.


------------------------------------------------------------
CONSOLE METHODS
------------------------------------------------------------

  Method              | Description
  --------------------|------------------------------------------
  console.log()       | Prints output to the console
  console.table()     | Displays data as a formatted table (great
                      | for objects and arrays)

  Example:
    console.log(studentName);              // Pulkit
    console.table({studentName, studentId});
    // Displays a table with (index | Values) columns


------------------------------------------------------------
KEY TAKEAWAYS
------------------------------------------------------------
  1. Use const by default; switch to let only if value changes.
  2. Never use var in modern JS code.
  3. Variable names are case-sensitive.
  4. console.table() is useful to inspect objects/arrays clearly.
